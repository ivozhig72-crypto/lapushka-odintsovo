Лапушка — резервная статическая копия сайта

Файлы сайта: index.html, styles.css, app.js. Изображения находятся в assets/.
Откройте index.html через статический хостинг (например, Netlify Drop или Cloudflare Pages).

Важно: это подготовленная резервная сборка на основе экспортированного кода и доступных фотографий. Часть изображений карточек услуг заменена фотографиями из архива реальных фото, поскольку исходные картинки карточек не входили в экспорт. Логотип добавлен из отдельного изображения пользователя; его качество невысокое. После загрузки обязательно проверьте сайт и кнопки.

Шрифты подключаются через Google Fonts; при отсутствии интернета будут использованы запасные шрифты. Телефонные ссылки и ссылка на Яндекс Навигатор сохранены.


Исправление карточек направлений: изображения восстановлены из предоставленных пользователем скриншотов оригинального сайта. Это не исходные полноразмерные файлы Manus; качество зависит от скриншотов.

Проверка резервной сборки (15.10.2026): тематические изображения карточек услуг сопоставлены с направлениями. Исправлены две ошибочные ссылки, где иллюстрации шахмат и детского психолога показывались как фотографии интерьера/ресепшена: галерея кабинета использует 1000004451.jpg, блок контактов — 1000004476.jpg. Публичный сайт Netlify этим архивом не изменяется, пока вы отдельно не загрузите архив.
